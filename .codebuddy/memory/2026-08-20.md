## 插件「修改不可改文件」需求变更 + T077/T079 范围收敛

### 用户需求（权威，覆盖此前 replace 设计）
- **添加插件时必须提供 WASM 文件**；**修改插件时不能修改插件文件**。
- edit 时 `identifier` / `version` / `runtime` **三者全部锁定**（只读），只能改 `name` / `description` / `capabilities` / `resource_limits`。
- 直接后果：**T079 ②「edit replace 元数据切换」作废**——修改插件不允许换文件，`PluginStore::replace` 不必实现。

### 本轮实现（`crates/hivegui/src/ui/plugin_view.rs`）
1. 删除 `save_wasm_locally`（原 `std::fs::copy` 覆盖文件的死代码，edit 分支唯一调用方）。
2. `save` 的 edit 分支：移除 replace 分支与 `keep_existing` 变量；`s3k` 恒等于 `original_s3_key`，`sha`/`size_bytes` 保持原值，仅 `Plugin::update`（元数据）+ `Plugin::update_limits`。
3. `render` 表单：
   - 新增 `form_field_readonly(label, value, theme)` 只读字段渲染（复用 `Runtime` 行样式）。
   - identifier / version：`.when(!editing)` 渲染可编辑 Input，`.when(editing)` 渲染只读。
   - WASM 文件：`.when(!editing)` 渲染「选择 WASM 文件」按钮 + `PLUGIN_WASM_SELECTION`，`.when(editing)` 渲染只读「不可修改（添加后文件不可替换）」。
4. 修复闭包捕获：`cx.weak_entity()` 从嵌套 `move` 闭包提到外层 `let pick_weak = cx.weak_entity();`，避免 `cx`（`&mut Context`）被 move（E0382）。
